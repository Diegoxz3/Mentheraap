## 📖 Overview

MenthEraApp is an Android application designed to support mental well-being by helping users manage anxiety through breathing exercises, meditation, emotional journaling, and motivational content.

The application aims to provide accessible self-care tools that encourage healthy daily habits while offering a modern and intuitive user experience.

---

## ✨ Features

- 🌬️ Guided breathing exercises
- 🧘 Meditation sessions
- 📔 Personal journal to record emotions and thoughts
- 💬 Motivational messages
- ❤️ Anxiety management recommendations
- 🎨 Modern UI built with Material Design 3
- 📱 Responsive Jetpack Compose interface
